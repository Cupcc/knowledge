# 学习路径

这一页是整站的导航入口，目标是让你在很短时间内知道三件事：先看什么、每个板块解决什么问题、下一步该去哪里。

## 栏目分工

| 板块 | 作用 | 适合什么时候看 |
|---|---|---|
| [基础主题](/basics/) | 建立对 AI 核心概念、方法和边界的统一理解 | 想系统学习或补基础时 |
| [案例库](/cases/) | 看具体问题如何拆解、设计方案并落地 | 想把能力用于真实场景时 |

## 推荐阅读顺序

1. 先阅读 [大模型基础认知](/basics/llm-overview)，理解模型能力边界。
2. 再看 [Prompt Engineering 入门](/basics/prompt-engineering)，掌握交互与提示设计。
3. 接着阅读 [RAG 检索增强生成](/basics/rag-intro)，理解知识增强方案。
4. 最后进入 [AI Coding Agent 编排架构](/basics/ai-agent-workflow)，看复杂工作流如何组织。
5. 完成基础认知后，再进入 [案例库](/cases/) 对照真实使用场景。

## 如何使用这个知识站

- 想按路径学习：从 [基础主题](/basics/) 入口开始，按推荐顺序逐篇阅读。
- 想快速解决问题：直接去 [案例库](/cases/) 找最接近的场景，再回补相关基础主题。
- 想长期沉淀：优先关注每篇文档中的“适用场景”“常见误区”“复盘”部分。
