# 基础主题

这个板块用于建立稳定的认知骨架。每篇内容都尽量回答四类问题：它是什么、为什么重要、什么时候适合用、什么时候容易用错。

## 推荐路径

1. 从 [大模型基础认知](/basics/llm-overview) 建立术语和能力边界。
2. 阅读 [Prompt Engineering 入门](/basics/prompt-engineering) 形成交互设计意识。
3. 阅读 [RAG 检索增强生成](/basics/rag-intro) 理解知识增强方案。
4. 最后进入 [AI Coding Agent 编排架构](/basics/ai-agent-workflow) 看复杂能力如何编排。

## 阅读提示

- 如果你更偏产品视角，优先看“适用场景”和“常见误区”。
- 如果你更偏工程视角，优先看“核心原理”和“落地建议”。
- 如果你想快速落地，建议读完一个基础主题后，马上去 [案例库](/cases/) 找对应案例对照理解。
