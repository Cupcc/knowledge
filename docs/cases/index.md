# 案例库

案例页采用统一结构：问题背景、目标、方案结构、执行流程、效果、局限与复盘。这样做的目的是让每篇案例都能被横向比较，而不是只停留在灵感记录。

## 如何阅读案例

1. 先看“问题背景”，判断它是不是你当前的问题。
2. 再看“方案结构”和“执行流程”，理解能力组合方式。
3. 最后看“局限与复盘”，判断能否直接迁移到你的场景。
