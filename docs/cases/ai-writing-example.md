# AI 内容创作案例

> 当前状态：已完成基础版  
> 典型场景：公众号文章、短视频脚本、社媒文案、知识整理

## 问题背景

内容团队最常见的问题不是“完全不会写”，而是从选题到成稿的前半程耗时很长：找资料、搭结构、统一口径、改不同版本。AI 在这里最适合承担的是加速初稿与结构化整理，而不是完全替代最终判断。

## 目标

- 缩短从选题到可审稿初稿的时间
- 保持内容结构一致，方便多人协作
- 让同一素材可以扩展成不同渠道版本

## 方案结构

```text
选题输入
  -> 补充背景资料
  -> 生成大纲
  -> 生成初稿
  -> 按渠道改写
  -> 人工审核定稿
```

## 执行流程

### 1. 输入明确目标

先告诉模型内容类型、受众、发布渠道、长度和期望风格。例如是写公众号文章，还是短视频脚本，输出结构完全不同。

### 2. 给足背景材料

如果内容依赖产品信息、活动规则或已有资料，应该把这些材料先整理后再输入，否则模型容易写得流畅但失真。

### 3. 先大纲，再成稿

直接要求一步成稿，往往会让内容失去层次。先产出大纲并人工确认，可以明显减少后续重写成本。

### 4. 渠道化改写

一份核心内容可以拆成公众号长文、小红书短文、短视频脚本和海报文案。AI 在多版本改写上通常性价比很高。

## 提示词示例

```text
请根据以下背景资料，先输出一份面向新手用户的文章大纲。

要求：
1. 结构清晰，控制在 5 个一级部分以内
2. 语言尽量口语化
3. 先解释问题，再给解决方案
4. 不要编造资料中不存在的信息
```

## 效果与价值

- 明显加快大纲和初稿形成速度
- 更适合做“多版本输出”而不是“一次定稿”
- 能降低重复性文案劳动，让人工聚焦内容判断与质量把控

## 局限与复盘

- 高度依赖输入资料质量
- 涉及事实和政策时必须人工复核
- 品牌语气、情绪节奏和最终观点仍需要人工把关
